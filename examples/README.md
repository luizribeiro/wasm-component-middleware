# Examples

- [trace](trace/README.md) logs a nested export and its host imports.
- [deny](deny/README.md) combines logging with a function allowlist.
- [wasi-p2](wasi-p2/README.md) traces synchronous Preview 2 calls.
- [wasi-p3](wasi-p3/README.md) traces concurrent Preview 3 calls.
- [sandbox](sandbox/README.md) enforces descriptor-aware filesystem policy.
- [byte-budget](byte-budget/README.md) budgets relayed Preview 3 stream bytes.
- [random](random/README.md) replaces random values and limits random calls.
- [net-allowlist](net-allowlist/README.md) filters Preview 2 and 3 socket destinations.
- [http-allowlist](http-allowlist/README.md) filters complete outgoing HTTP requests.
- [run](run/README.md) runs and traces Preview 2 or Preview 3 command components.
